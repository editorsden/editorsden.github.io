## Why Learn from Wandering DP
Patrick O'Sullivan (The Wandering DP) hosts the definitive technical channel for working commercial cinematographers. Every breakdown provides precise 2D overhead lighting schematics, false color exposure readings, and uncompressed RAW frame grabs.

### Core Specializations
- **False Color & Exposure**: Nailing IRE values on skin highlights and shadow details using external light meters.
- **Overhead Lighting Schematics**: The exact placement of HMIs, ultra-bounces, and black solid flags.
- **Camera Package Strategy**: Choosing the right cinema sensors and anamorphic lenses for high-budget commercial briefs.
