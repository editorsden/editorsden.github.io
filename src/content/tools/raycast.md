## Overview

**Raycast** replaces macOS Spotlight with an extensible power tool tailored for creative professionals. For video editors, it acts as an instant bridge between your filesystem, web tools, and your NLE timeline.

### Editor Superpowers

- **Instant File Search**: Jump to any project archive, footage subfolder, or audio stem in milliseconds and drag it straight into Premiere or Resolve.
- **Deep Clipboard History**: Never lose an EDL path, audio timecode, YouTube URL, or hex color code again.
- **Custom Post-Production Scripts**: Trigger Shell or Python scripts to run FFmpeg proxy conversions, batch-rename rushes, or clear Premiere scratch disks directly from the keyboard.
