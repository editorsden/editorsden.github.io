## Overview

Created by Chris Vranos and distributed via aescripts + aeplugins, Composite Brush replaces tedious multipass keying workflows with intuitive brush-based color classification.

## Key Capabilities

- **Intuitive Click & Drag Sampling**: Click to designate which colors to keep or remove.
- **Advanced Color Transfer**: Intelligently despills edge fringe by borrowing neighboring unkeyed color pixels.
- **Timeline Performance**: Real-time GPU rendering with zero UI lag on 4K comps.
